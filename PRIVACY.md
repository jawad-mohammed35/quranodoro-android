# Privacy

Quranodoro Android stores preferences and productivity progress in the application's private device storage. It has no sign-in, ads, analytics, tracking SDK or cloud synchronization. Android cloud backup is disabled.

When you request recitation, your device connects over HTTPS to the selected mp3quran.net host. Like any streaming provider, that host receives standard connection information such as your IP address. Quranodoro does not send your saved productivity data with those requests.

Export uses Android's document picker and writes a JSON file at the location you choose. The file includes local preferences and progress. You control where that file is saved and shared. Removing the app clears its private local data. External links open in a separate app only when selected.

Notifications are optional. Required permissions and background behavior are documented in the README.
